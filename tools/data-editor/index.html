扫描的图片从哪里来？

编辑器读取本地 image，不会自动 fetch 或切换分支。先在 image 提交、推送图片，再切回 meme/...。若图片在另一台电脑上传，先 git fetch origin，到 image 执行 git pull --ff-only origin image 后再切回投稿分支。
