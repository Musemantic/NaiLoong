# 社区表情包投稿

## 适合谁

只想分享表情、不想使用 Git 命令或编辑 JSON 的贡献者。请在[开放的投稿 Issue 列表](https://github.com/lin-alg/NaiLoong/issues?q=is%3Aissue+is%3Aopen+label%3Asubmission)中找到置顶的「奶-hub 表情包投稿区」，在评论区贴上图片链接和简单说明。不要为单张表情新建项目反馈 Issue。

图片统一放在自己公开 Fork 的 `image` 分支；即使以后不再贡献，也请保留这个公开仓库，避免网站图片失效。

## 上传与留言

1. 打开奶-hub 仓库，点击 **Fork → Create fork**，将仓库复制到自己的 GitHub 账号。
2. 打开自己的 Fork，在分支菜单中输入 `image` 并创建该分支。
3. 切换到 `image` 分支，点击 **Add file → Upload files**，上传图片并提交。
4. 上传完成后打开图片文件，复制浏览器地址栏中 `github.com/你的用户名/NaiLoong/blob/image/...` 形式的链接。
5. 回到置顶投稿 Issue，在评论中填写图片链接和下方信息。不要把图片直接上传到评论，也不要使用其他图床。

```text
标题：奶蛙狂笑
角色：奶蛙（naiwa）
分类：动图（animated）
标签描述：大笑、日常（可选，不确定可留空）
```

不需要提供数字标签；提交数据 PR 的贡献者或维护者会根据角色的 `tags.json` 选择标签。暂时只有动图和静态图分类；极短视频请先转换为 GIF，较长视频不收录。

单张图片严格不超过 5 MB，建议压缩到 2 MB 以下以减少加载时间。支持常见静态图片和 GIF。

## 投稿后

维护者核对图片和说明后，会把记录加入对应分类文件。发现图片链接失效或说明有误时，可以在原评论下补充信息。
